# CodeAlpha_ImageGallery

A responsive image gallery built with **HTML, CSS, and JavaScript** as part of the CodeAlpha Frontend Development Internship.

## 🖼 Features
- Contact-sheet style responsive grid layout
- Category filters (Landscape, Portrait, Urban, Nature)
- Hover effects with a grayscale-to-color reveal and smooth zoom transition
- Full-screen lightbox view with:
  - Next / previous navigation (buttons + keyboard arrow keys)
  - Image counter
  - Close on click-outside or `Esc`
- Fully responsive across desktop, tablet, and mobile
- Smooth fade-in animation as images load

## 🛠 Built With
- HTML5
- CSS3 (Grid, animations, transitions)
- Vanilla JavaScript (no frameworks/libraries)

## 🚀 How to Run
1. Clone this repository
2. Open `index.html` in any browser

No build step or dependencies required.
